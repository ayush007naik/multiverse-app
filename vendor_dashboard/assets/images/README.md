# MULTIVERSE Vendor Login Banner

## Instructions:

1. **Create or obtain a cyberpunk-themed banner image**
   - Recommended size: 1920x1080px or 1600x900px
   - Format: PNG or JPG
   - Theme: Dark, futuristic, neon accents (orange/purple)

2. **Save the image here:**
   - File name: `vendor_login_banner.png`
   - Location: `vendor_dashboard/assets/images/vendor_login_banner.png`

3. **Design suggestions:**
   - Dark background (#0D0518 or similar)
   - Neon grid patterns
   - Futuristic city or tech elements
   - Orange (#FF6A00) and purple (#9C27B0) accent colors
   - Subtle glow effects

4. **After adding the image:**
   ```bash
   cd vendor_dashboard
   flutter pub get
   flutter run -d chrome
   ```

## Alternative:

If you don't want to add an image, the login screen will automatically show a beautiful gradient cyberpunk background as fallback.
